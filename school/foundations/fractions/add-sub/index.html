Add & Subtract Fractions

Same denominator = just add tops

Mode:
① Hook

Slices of the Same Pizza

1/4 + 2/4 = 3/4. Easy — same denominator, just add numerators. But 1/3 + 1/4? You need to find a common denominator first. Think of it as converting to the same "size" of slice before counting them up.

② The Hack

Common Denominators Are the Key

⚡ Core Insight
Same denominator: add/subtract numerators. Different denominators: find LCD, convert both, then add/subtract tops.
🎯
Same Denominator
Add/subtract numerators only. 2/7 + 3/7 = 5/7. The denominator stays the same.
🔄
LCD
Least Common Denominator — smallest number both denominators divide into. Convert both fractions first.
⚖️
Mixed Numbers
Convert to improper fractions, add, then convert back. Keep the process organized.
